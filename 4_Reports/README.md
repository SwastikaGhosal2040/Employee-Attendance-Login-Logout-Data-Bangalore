# Reports

This folder contains the final reporting outputs of the Employee Attendance Analytics project.

The reports are organized into two main sections:

- `Analysis_Outputs` — visualizations, statistical summaries, and hypothesis-testing outputs generated from the data analysis notebook.
- `Dashboard_Images` — screenshots of the three pages of the Employee Attendance Analytics Dashboard created using Looker Studio.

---

## 2. Dashboard Images

The `Dashboard_Images` folder contains screenshots of the three pages of the Employee Attendance Analytics Dashboard created using Looker Studio.

The dashboard provides an interactive view of employee attendance, working hours, productivity, overtime, workforce composition, and attendance patterns for Bangalore during Q1 2026.

---

### Page 1 — Dashboard Overview

![Employee Attendance Dashboard - Page 1](Dashboard_Images/Employee_Attendance_Dashboard_Page1.png)

Page 1 provides an overall operational view of employee attendance and workforce activity.

It includes:

- Total Employees
- Attendance Rate
- Average Hours Worked
- Average Net Productive Hours
- Late Arrival Rate
- Early Exit Rate
- Average Overtime Hours
- Work Mode Distribution
- Overall Productivity Ratio
- Attendance Records by Office Location
- Employee Distribution by Employment Type and Shift Type

The page also provides filters for attendance month, department, designation, employment type, office location, shift type, work mode, attendance status, gender, and weekday.

---

### Page 2 — Productivity and Overtime Analysis

![Employee Attendance Dashboard - Page 2](Dashboard_Images/Employee_Attendance_Dashboard_Page2.png)

Page 2 focuses on productivity, late arrival, overtime, and workforce distribution across departments.

It includes:

- Total Employees
- Attendance Rate
- Average Hours Worked
- Early Exit Rate
- Average Late Arrival by Shift Type
- Impact of Overtime on Net Productive Hours
- Average Overtime Hours by Department
- Workforce Distribution by Department

This page provides a more detailed view of how working patterns, overtime, shift types, and departments relate to employee productivity and attendance behavior.

---

### Page 3 — Attendance and Workforce Analysis

![Employee Attendance Dashboard - Page 3](Dashboard_Images/Employee_Attendance_Dashboard_Page3.png)

Page 3 focuses on attendance, leave patterns, employment types, and department-level productivity.

It includes:

- Total Employees
- Productivity Ratio
- Average Net Productive Hours
- Average Hours Worked
- Attendance Rate
- Leave Type Distribution
- Employment Type Distribution
- Attendance Records by Department
- Average Net Productive Hours by Department

This page provides a detailed view of leave patterns, workforce composition, department-level attendance records, and productive working hours.
